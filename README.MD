# Blog Application

## Project Overview
A simple Blog Application developed using HTML, CSS, JavaScript, Node.js and Express.js.

## Module 1 - Frontend Development
- User Registration
- User Login
- Dashboard
- Create Blog
- View Blogs

## Module 2 - Backend Development
- Node.js and Express.js server
- User Registration API
- User Login API
- Create Blog API
- Get All Blogs API
- Frontend and Backend Integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run
1. Install Node.js.
2. Run `npm install`.
3. Run `node server.js`.
4. Open `http://localhost:5000`.
