# 📝 Blog Application

A full-stack Blog Application developed as part of the Codomax Digital Solutions Internship, featuring user authentication and blog management.

## 🚀 Project Overview

This project allows users to register, log in, create blog posts, and view published blogs through a simple and user-friendly interface.

## ✨ Features

- User Registration
- User Login
- Create Blog Posts
- View All Blogs
- Frontend and Backend Integration
- REST API Development

## 🛠️ Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js
- REST APIs

## 📂 Project Structure

- `index.html` – Home Page
- `register.html` – User Registration
- `login.html` – User Login
- `dashboard.html` – Blog Dashboard
- `create-blog.html` – Create Blog Page
- `style.css` – Styling
- `script.js` – Frontend Functionality
- `server.js` – Backend Server
- `package.json` – Project Dependencies

## 🔌 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/register` | Register User |
| POST | `/api/login` | Login User |
| POST | `/api/blogs` | Create Blog |
| GET | `/api/blogs` | Get All Blogs |

## ⚙️ How to Run

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   `npm install`

5. Start the backend server:

   `node server.js`

6. Open the frontend using Live Server.

7. Backend runs at `http://localhost:5000`.
